# Белочка поднимается по ели — комплект графики

Нежный иллюстративный стиль, согласованный по второму образцу. Комплект для просмотра и утверждения графики перед разработкой игры.

## Что открыть

Откройте `index.html` в обычном браузере. Страница работает без сборки, установки библиотек и внешних сервисов. Рядом должны лежать `preview.js`, `manifest.js` и папка `assets`.

На странице есть просмотр высоты сцены, выбор картинки для карточки, десять карточек слов, три демонстрации движений и галерея PNG. Управление и подписи на этой странице служат только проверке материалов и не относятся к будущему интерфейсу игры.

## Состав

- **23 рабочих PNG** в папке `assets`.
- `style-reference.png` — утверждённое направление рисовки.
- `scene-manifest.json` — размеры, координаты кадров, точки опоры, масштаб, 11 веток, параметры камеры, порядок слоёв и 10 заданий.
- `word-cards.json` — порядок слов и связь с шишками.
- `WORDS.md` — описание десяти карточек.
- `manifest.js` — те же данные для локального просмотра без загрузки JSON через fetch.
- `index.html` и `preview.js` — просмотр материалов и демонстрация анимаций, без игровых заданий.
- `generation-prompts.json` — описания, использованные во встроенном imagegen.
- `SCENE.md` — схема сборки и поведения сцены.
- `QA.md` — результаты проверки.

## Как устроена анимация

Белочка подготовлена **кадрами полного персонажа**, а не набором разрозненных лап и головы. Это сохраняет цельный рисунок меха и не требует скрывать стыки частей. Дыхание дополняется очень небольшим растяжением вокруг точки опоры; прыжок перемещает кадры по дуге; приветствие использует несколько положений лапки.

PNG сами по себе статичны. Движение видно в `index.html`; в будущей игре его будет выполнять JavaScript. Атласы не нужно вручную разрезать: координаты `source` в манифесте позволяют рисовать отдельные кадры через Canvas `drawImage`.

**Не делите атласы на равные клетки.** Иллюстрации имеют немного разные отступы. Используйте точные прямоугольники `source`, точки опоры `anchor` и `worldScale` из манифеста. Предварительные точки опоры можно тонко подстроить при финальной сборке.

## Изменение упаковки относительно первоначального перечня

Ель сохранена одним непрерывным PNG. Пять частей заданы областями этого же изображения в манифесте, поэтому они не могут разойтись по цвету или рисунку. Отдельной картинки для финальной верхушки нет: она уже включена в дерево.

Для 11 опор используются шесть разных форм веток с индивидуальными масштабами и положениями. Передняя хвоя повторно используется с нужным размером. Это уменьшает объём загрузки и сохраняет единый стиль. Все 11 точек посадки перечислены отдельно.

## Загрузка в репозиторий

1. Распакуйте ZIP.
2. Загрузите **содержимое** папки `squirrel-spruce-assets` в выбранную папку репозитория, сохранив структуру и имена файлов.
3. Для GitHub Pages корнем просмотра должна быть папка, содержащая `index.html`.
4. После публикации откроется страница согласования графики. Это ещё не готовая логопедическая игра.

Текущая страница не предназначена для итоговой вставки в Genially: в ней есть инструменты проверки. После утверждения графики будет создан отдельный игровой экран 16:9 с требуемой минимальной механикой.

## Что намеренно не входит

Распознавание речи, звуки, исполняемая игровая механика и финальная логика перезапуска. Картинки десяти слов уже созданы по утверждённому списку; их последовательность задана в манифесте. По ТЗ сначала утверждается графика, затем пишется игра. Надпись «Мы добрались до верхушки!» и кнопку «Играть ещё» следует сделать текстом интерфейса при разработке, а не растровыми картинками.

Все новые изображения созданы встроенным imagegen. Платная стоковая иллюстрация по ссылке не скачивалась и не включена в комплект.
